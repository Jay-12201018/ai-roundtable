界面约定（不涉及契约）：
- 本场信息 › 产物 列出四类，每类说明它是什么；讨论进行中或有请求在途时，按钮不可用并写明原因。已有的产物显示标题、状态、是否受影响和版本数，点开进入阅读器。

- 修改是带实时校验的 JSON 编辑框：问题逐条列出，点"第 N 行"光标跳到那一行；校验通过前"保存为新版本"不可用；关闭阅读器不会丢掉未保存的修改（本窗口内按版本保留）。
- 条目的"第 N 条"来源可以点，阅读器关闭，时间线滚到那条发言并短暂高亮，停止跟随最新消息。
