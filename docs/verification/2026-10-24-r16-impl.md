## 做了什么

| 范围 | 内容 |
| --- | --- |
| A 基础 | `src/renderer/theme/`：浅色 / 深色 / 跟随系统三套 token（与设计说明同名同值）、基础样式（字体栈、焦点环、减少动画、取消 `body min-width:1080px`）、`useTheme` / `useLayout`。`src/renderer/components/ui/`：按钮（主要 / 次要 / 安静 / 危险，两档）、图标按钮（必带名称）、状态胶囊、标签、头像、提示条、提示卡片、抽屉（遮罩、Esc、焦点限制与归还）、对话框、标签页、复制。旧的 `styles.css` 改为引入 token，并把房间 / 设置 / 工作流 / 用量页的旧变量名映射到新 token，这几页先保持原结构。 |
| B 外壳 | 左侧栏（房间、当前房间的讨论记录（新到旧）、新讨论、底部用量（本月金额）与设置）；顶栏（标题、状态胶囊与说明、预算胶囊、成员头像、本场信息开关）；右侧「本场信息」（进度 / 成员 / 指令 / 产物 四个标签，产物写“即将推出”，底部「运行详情（排查问题时用）」）。≥1280 三栏；1024–1279 本场信息变右侧抽屉；<1024 侧栏也变左侧抽屉。窗口最小尺寸在 main 上已是 800×600，没有再改；`createMainWindow.ts` 只把启动底色从深蓝改成跟随系统的新画布色（单独的 `wire:` 提交）。 |
| C 时间线 | 消息三层：身份行（头像、名字、模型显示名、主持人点名 / 已由摘要代替 / 摘要后已修改 标签、编号）→ 需要处理时才出现的提示条（受影响、写到上限、正在重新生成、生成失败 / 已中止），每条只有一个下一步按钮并写最高花费 → 浅色页脚（版本切换与来源、金额按钮、复制 / 修改 / 重新生成 / 请求详情）。主持人插话是右侧气泡。摘要卡片（覆盖范围、生效状态、待确认时「确认使用」为主按钮、受影响时「重新生成摘要…」带最高花费）。时间线末尾的提示卡片：预算停下（追加并继续）、已停止 / 运行失败（只在 Main 允许时出现重试 / 续写，写明可能再次计费与最多约多少钱）、已中断（检查 / 恢复 / 放弃）、同步失败（重试同步）、上下文接近上限（生成摘要…）。安全 Markdown / GFM：`react-markdown` + `remark-gfm` + `rehype-sanitize`（均为已声明依赖），白名单元素，原始 HTML 当文字显示，只有 https 链接可点且经 Main 原生确认（R01 规则），图片不加载，代码块有语言名与「复制」，表格横向滚动；修正了中文常见的 `**范围：**3 栋` 加粗不生效。长历史：超过 150 条时按测得高度窗口化；在底部时跟随，向上翻、选中文字、看旧版本或编辑时停止跟随，出现「有新消息 · 回到最新」；每场讨论的阅读位置在切换后保留。 |
| D 输入框 | 未开始：多行「讨论目标」，下方是讨论方式、预算、每回合后暂停、「⋯」（预算与单次发言上限在同一弹层，无效时保持展开并说明原因），⌘/Ctrl+Enter 开始，输入法组合中的回车只确认候选。运行中：同一个框是插话框，Enter 发送、Shift+Enter 换行、IME 安全；`@` 或「点名」打开点名菜单（方向键、Enter、Esc，写明谁能点、为什么不能）；**D4**：带 `@成员` 的插话由 Renderer 依次发 `setOverride` 与 `interject` 两个已有命令，任一步失败都在输入框上方说明哪一步成功、哪一步没发，已成功的点名不撤回、再发一次不会重复点名，一次点两位或点不可点名的成员会在发送前拒绝；「设为持续指令」。控制条 `停止 ｜ 下一步 · 暂停/继续`：开始讨论 → 暂停 → 继续 轮流占同一个槽位（同宽同位置，D098），停止红色描边并隔开，确认弹层在按钮上方、焦点在「不停止」、Esc 返回，请求在途时写明可能已计费和预留上限。`HostPanel` / `HostTimeline` 退役，功能对照见下节。 |

实操中发现并修复的问题：开始讨论时本场信息才出现，把中间栏挤窄导致「暂停」不在原位（改为开始前就占位）；中文加粗不渲染（满屏 `**`）；另一场讨论暂停中时开新讨论只报“启动协作失败”（改为开始前说明是哪一场、给「回到那场讨论」）；讨论结束后输入框还留着上一场的目标（开始后清空）；主持人操作的确认提示一直挂着（8 秒后消失，错误保留）；停止确认弹层关闭后焦点丢失；根元素无背景色。

## 与设计稿的差异

见报告正文“与设计稿的差异”一节，这里列出要点：

1. 讨论方式仍是原工作流页面（胶囊打开），不是设计里的对话框；“按房间记住”（D2）未做 —— 属于第二批 F。
2. 侧栏房间不显示人数、没有“+ 新建房间”，「管理房间与成员」进入原房间页（页内还有自己的房间列表，与侧栏重复）—— 第二批 F。
3. 状态说明写“第 N 回合 · 某某正在发言”，没有设计里的“第 3/5 步 · 起草者正在修订”；“下一位”行不写阶段名；发言头部没有阶段标签（修订、复审）。
4. 金额点击后在页脚下方展开「请求详情」区域，不是浮动弹层。
5. 停止 / 失败 / 中断后，输入框仍是插话框，槽位是「新讨论」（设计稿没有画这一状态）。
6. 窗口化阈值 150 条（之下全部渲染）；设计说明写的是始终虚拟化。
7. 新增设计稿里没有的两处：另一场讨论未结束时在开始前拦下并说明；开始后清空目标框。
8. 外观切换暂放在设置页顶部，设置页本身未改版。
9. 连接向导与模型服务的价格审核文案（OpenAI、其他兼容服务也要写“价格尚未审核，暂时不能用于讨论”）不在本批范围，没有改。
